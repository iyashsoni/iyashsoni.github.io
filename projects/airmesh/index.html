AirMesh

Peer-to-peer file sharing in your browser. No servers, no signup, no upload limits — just drop a file and watch it fly.

Open AirMesh Source code
Features

Everything you need,
nothing you don't.

🔒
End-to-end encrypted
Files are encrypted with DTLS-SRTP over a direct WebRTC data channel. No middleman ever sees your bytes.
⚡
Zero servers
Files stream directly device-to-device. Nothing is uploaded or stored anywhere. The signaling server only handles the handshake.
📱
QR code pairing
Scan a QR code or type a 6-character code. Connect two devices in under 10 seconds, no account needed.
🌍
Cross-platform
Works in any modern browser — iOS, Android, macOS, Windows, Linux. If it has a browser and WebRTC, it works.
♾
No file size limit
Because files never touch a server, the only limit is your network and disk. Send gigabytes if you want.
📦
Installable PWA
Add AirMesh to your home screen for a native-like experience. Works offline for the UI layer.
How it works

Three steps,
then it's done.

1
Open AirMesh on both devices
Visit airmesh.vercel.app on both the sender and receiver device. No app install required.
2
Pair with a QR code or 6-character code
One device shows a QR code, the other scans it — or just type the short code. A direct WebRTC channel opens between the browsers.
3
Drop files and they stream across
Drag and drop or tap to select. Files stream encrypted from sender to receiver in real time. No waiting for uploads.
