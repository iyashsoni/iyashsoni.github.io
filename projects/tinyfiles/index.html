Features

Tiny by design.
Private by default.

🔒
100% private
Files are processed using WebAssembly in your browser tab. Nothing is ever uploaded to any server.
⚡
Instant compression
No upload wait times. Processing happens locally at full CPU speed, so results are near-instant.
📦
Batch + ZIP download
Compress up to 20 files at once and download them all in a single ZIP. Ideal for bulk workflows.
🎚
Quality presets
Adjustable quality slider lets you find the right balance between file size and visual fidelity.
📴
Works offline
Once the page loads, no network required. Compress files anywhere — on a plane, in the field, wherever.
🆔
No account needed
Open the page and start compressing. No email, no sign-up, no payment. Just free and fast.
