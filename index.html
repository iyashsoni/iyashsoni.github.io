About me

Born curious.
Built different.

I'm Yash — raised in Ahmedabad, forged in Bangalore. A BE in IT from VGEC and an MTech from IIIT-Bangalore later, I've spent 8+ years at IBM turning hard problems into systems that don't wake you at 3 a.m.

Today I lead the IBM Cloud Object Storage control plane — edge, provisioning, identity, billing and metering — across ~820,000 instances, with a team of 8 engineers. Lately I've gone deep on building with AI: thought partner, teacher, pair programmer. On the side I ship privacy-first web and iOS apps.

When I step away from architecture, you'll find me obsessing over markets, meditating on existence, hunting the perfect 90s track, or asking questions that have no clean answers.

and thoroughly hooked.

At work · IBM

Agentic engineering, daily

I use an internal agentic coding assistant every day — custom skills, subagents, slash commands, and modes — for code generation, legacy-code modernization, automated vulnerability detection and remediation, and first-pass code review.

I equipped all 8 engineers on my team with agentic AI tooling — now in daily use for code generation, with more advanced workflows (automated review, modernization, and testing) coming online.

Experience

A decade, mostly
at petabyte scale.

Eight years at IBM — from mobile backends to owning a cloud storage control plane that quietly keeps hundreds of thousands of instances running.

820K Active COS instances under my control plane
14.7M Control-plane API requests handled / month
PB-scale Zero-downtime SoftLayer → IBM Cloud migration
~$15K/mo Infrastructure cost cut by consolidating workloads

  1. Software Engineering Lead

    2023 — Present

    IBM · Cloud Object Storage · Bangalore

    • Owns the COS control plane & billing — provisioning/deprovisioning, credential and HMAC issuance, IAM, and usage-based metering (Class A/B requests, storage, bandwidth, retrieval) across ~820,000 active instances.
    • Operates the edge layer fronting the control plane (IBM Cloud Internet Services) — load balancers, origin pools, health checks, TLS, and monitoring — handling ~14.7M API requests/month.
    • Architected and delivered a zero-downtime, petabyte-scale migration of legacy SoftLayer instances to IBM Cloud with no movement of object data — recreating each instance under its original UUID and migrating HMAC credentials to IAM, so customer apps kept working with the same IDs and keys, zero client-side changes.
    • Led the migration of IKS Classic clusters to OpenShift on VPC, modernizing the runtime and network-security posture (VPC, security groups, private workers).
    • Cut infrastructure cost by ~$10–15K / month by consolidating workloads onto under-utilized clusters.
    • Designed an in-product upgrade experience for Free-tier customers that lifted Standard-tier conversion by ~10–15%.
    • Leads a team of 8 engineers; escalation owner for premium-customer issues and runs internal enablement on COS tooling and diagnostics.

  2. Software Engineer

    2021 — 2023

    IBM · Cloud Object Storage · Bangalore

    • Built and shipped the customer-facing console UI for COS — instance management, credentials, and usage & metrics views.

  3. Software Engineer

    2018 — 2021

    IBM · MobileFirst Platform · Bangalore
